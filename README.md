# Portfólio — André Felipe

Meu portfólio pessoal, desenvolvido com HTML, CSS e JavaScript. A página apresenta minha formação, alguns projetos de estudo e os links para acompanhar meu trabalho no GitHub ou entrar em contato.

A proposta é simples: uma apresentação direta, com tema escuro e foco nos projetos.
[Clique aqui](https://portfolio-andre-felipe.vercel.app/)

## Sobre mim

Sou André Felipe Pereira de Paiva, estudante de Ciência e Tecnologia na UFRN e de Análise e Desenvolvimento de Sistemas na Universidade Potiguar. Tenho interesse em desenvolvimento de software e busco minha primeira oportunidade na área.

## Tecnologias

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** tema escuro e layout responsivo.
- **JavaScript:** abertura e fechamento do menu em dispositivos móveis.

O projeto não utiliza frameworks nem depende de instalação de pacotes.

## Conteúdo

- Apresentação pessoal e formação acadêmica.
- Projetos em destaque: To-Do List, PetLife e Snake Game.
- Resumo dos conhecimentos e da formação complementar.
- Links para GitHub, LinkedIn e contato por e-mail.

## Organização dos arquivos

| Arquivo ou pasta | Função |
| --- | --- |
| `index.html` | Conteúdo e estrutura do site |
| `styles.css` | Estilos, cores e regras de responsividade |
| `script.js` | Comportamento do menu móvel |
| `assets/` | Imagens dos projetos e certificado de HTML5 |
